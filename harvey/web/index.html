Cos’è Harvey?

Harvey è un assistente commerciale basato sull’intelligenza artificiale. Cerca potenziali clienti, prepara email personalizzate, le invia tramite il servizio configurato e gestisce le risposte. Puoi controllare il lavoro e approvare i messaggi da questo pannello. Prima di attivare campagne, verifica requisiti di consenso e regole applicabili ai destinatari.

Harvey usa il tuo abbonamento Claude oppure, scegliendo Codex, il tuo piano ChatGPT, entro i relativi limiti di utilizzo. I dati di lavoro restano nella cartella del progetto; i contenuti necessari vengono inviati ai servizi configurati e al modello selezionato.

Primi passi

Per iniziare:

1. Configura il prodotto e verifica il modello con harvey status --check
2. Scegli i segnali e una fonte nella sezione Ricerca aziende
3. Per gli invii, collega una casella e un verificatore nelle Impostazioni
4. Controlla i requisiti dei destinatari, poi avvia Harvey dai Controlli

La sezione Oggi mostra i passaggi completati e quelli ancora da configurare.

Dove si trovano i dati

Configurazione, conoscenza commerciale e dati di lavoro si trovano nella cartella del progetto. Il login del modello resta nella configurazione del relativo servizio.

Come ottenere le credenziali

Chiave API Instantly (alternativa facoltativa)

Instantly è una delle integrazioni disponibili per inviare le campagne. Puoi usare anche Gmail o SMTP/IMAP.

1. Registrati su instantly.ai (l’accesso API richiede il piano Growth)

2. Apri Settings > Integrations nel servizio

3. Copia la chiave API

4. Incollala nella sezione Impostazioni di Harvey

Credenziali LinkedIn (facoltative)

Inserendo email e password, Harvey può cercare contatti su LinkedIn tramite browser. Questa automazione può violare le condizioni del servizio. Nel ciclo Halvea LI-01 inviti e messaggi restano manuali.

Senza queste credenziali, Harvey può cercare contatti sul web e sui siti aziendali.

Cloudflare Browser Rendering (facoltativo)

Viene usato durante il training per leggere il sito del prodotto. Può analizzare pagine che richiedono JavaScript, non leggibili dal crawler HTTP integrato.

1. Registrati su Cloudflare (controlla costi e limiti del tuo piano)

2. Apri Workers & Pages > Browser Rendering nel servizio

3. Crea un token API con permesso Browser Rendering: Edit

4. Inserisci ID account e token API nelle Impostazioni

Senza Cloudflare, Harvey usa il crawler integrato, che legge le pagine HTML ma non esegue JavaScript.

Problemi comuni

"command not found: harvey"
Attiva prima l’ambiente virtuale: source .venv/bin/activate
Instantly restituisce un errore API 401
Controlla la chiave e che il piano includa l’accesso API. La trovi in Settings > Integrations nel pannello di Instantly.
Le chiamate a Claude non funzionano
Assicurati di aver eseguito claude login nel terminale e di avere un abbonamento compatibile attivo. Harvey usa quel piano, senza una chiave API separata.
Le chiamate a Codex non funzionano
Con brain.provider: codex, scegli un modello disponibile nel catalogo del tuo account, ad esempio gpt-6.1-sol, oppure lascia brain.model vuoto per la selezione automatica. I modelli usano un catalogo temporaneo che disabilita gli strumenti. Con brain.model: gpt-6-luna resta attivo il trasporto solo testo dell’abbonamento ChatGPT e la CLI non riceve le istruzioni di generazione. Esegui codex login scegliendo “Sign in with ChatGPT”. Il login con chiave API non è consentito. Harvey non rinnova il login: se scade, usa Codex oppure esegui nuovamente codex login. Questa integrazione richiede Codex CLI 0.159.3 su macOS o Linux e rifiuta le altre versioni. Quando Codex non è utilizzabile, Harvey sospende il lavoro senza modificare risposte o invii in coda. Il comando harvey status --check verifica la configurazione su richiesta. Se il controllo di isolamento fallisce, controlla che nessuna configurazione esterna riattivi strumenti, hook, server MCP o endpoint personalizzati. Harvey non passa automaticamente a Claude.
Le email iniziali restano in attesa
Imposta il tuo indirizzo postale reale in compliance.postal_address nel file di configurazione. Harvey aggiunge l’indirizzo e la frase compliance.opt_out_line alle email iniziali. Senza indirizzo, queste email restano in coda; le risposte alle conversazioni continuano normalmente. La frase predefinita per interrompere i contatti è in italiano. Le risposte “no grazie” interrompono i contatti anche senza classificazione del modello.
Harvey non trova potenziali clienti
Controlla che il profilo cliente nella configurazione attiva contenga settori, ruoli e aree geografiche realistici. Conferma i segnali da raccogliere. Nella sezione Attività puoi vedere cosa ha tentato Harvey.
